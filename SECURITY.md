# Security

Please report suspected vulnerabilities through GitHub's **Report a vulnerability** action on this repository's Security tab when available. If private reporting is unavailable, open an issue asking for a private contact method without including exploit details, credentials, captured screen content, or personal data.

DuoLid's security boundaries include Screen Recording consent, exclusion of the overlay from capture, update signature verification before extraction, the signed feed, and the release-signing identity. A display effect is not a privacy or authentication boundary.

Do not attach private signing keys or raw system crash reports. The built-in technical report excludes screen images and account details. No public production release is available yet; the first supported beta will be listed in the release notes.
